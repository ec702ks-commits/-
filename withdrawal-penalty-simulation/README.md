# 중도해지 패널티 시뮬레이션

퇴직연금(DC/IRP) 기존상품을 **만기까지 유지**했을 때와, **중도해지(패널티 적용) 후 신상품에 지금 금리로 재예치**했을 때를 비교해서 고객에게 유불리를 제안하는 도구입니다.

## 특징

- **개인정보/고객정보가 기기 밖으로 나가지 않습니다.** 모든 입력과 계산은 브라우저 안에서만 처리됩니다.
- 기존 `DC·IRP 만기예정 안내 문자` 도구와는 완전히 별도로 동작합니다(엑셀 업로드 없음, 전부 직접 입력).
- 신상품 재예치 옵션(기간/금리)은 시기·거래처마다 다르므로 매번 화면에서 직접 입력하며, 기간을 자유롭게 추가/삭제할 수 있습니다.

## 사용 방법

가장 간편한 방법: `./build.sh`를 실행하면 `dist/중도해지_패널티_시뮬레이션.html` 파일 하나가 만들어집니다. 이 파일을 휴대폰/PC에 저장해두면 인터넷 연결 없이 바로 사용할 수 있습니다.

또는 `index.html`을 브라우저로 직접 열어도 됩니다.

1. **고객/기존상품 정보**: 가입원금, 가입일, 만기일, 약정금리, 해지(오늘) 기준일을 입력합니다.
2. **만기까지 유지 시**: 만기 시 예상 수령액을 입력합니다. 회사 시스템에서 조회한 정확한 값을 넣는 것이 가장 정확하며, 모르면 "이 값 채우기"로 단리 추정치를 사용할 수 있습니다.
3. **중도해지 패널티**:
   - 당사 상품처럼 해지패널티/해지적립금을 정확히 아는 경우 → **해지적립금 직접입력**
   - 타사 신탁상품처럼 "중도해지 시 적용이율이 약정금리의 80%" 식으로만 아는 경우 → **적용이율 비율로 계산** (경과기간 동안 약정금리 × 비율로 계산)
4. **신상품 재예치 제안금리**: 제안할 기간(예: 1년/2년/2.5년/3년/5년)과 금리를 입력합니다. 기간은 자유롭게 추가/삭제 가능합니다.
5. **작성자 정보(선택)**: 이름/부서/연락처를 입력하면 결과 문서 하단에 표시됩니다.

화면 아래 "결과 요약 미리보기"에 두 시나리오 비교표가 실시간으로 만들어집니다. **"PDF로 저장(인쇄)"** 버튼을 누르면 인쇄 창이 열리고, 인쇄 대상(프린터) 선택에서 **"PDF로 저장"**을 고르면 지금 화면 그대로 PDF 파일로 저장되어 고객사에 제시할 수 있습니다.

## 참고

- 신상품 재예치 만기일이 기존상품 만기일과 다를 수 있으므로, 비교표에 시점 차이를 함께 표시합니다. 최종 판단 시 시점 차이를 함께 안내해주세요.
- 모든 금액 계산은 **단리** 기준 추정입니다. 실제 상품의 이자 계산 방식(단리/복리), 세금, 수수료에 따라 실수령액과 차이가 있을 수 있습니다.
- 신상품 금리 목록과 작성자 정보는 다음 사용을 위해 이 기기의 브라우저 저장소에 남습니다("전체 초기화"를 눌러도 유지되며, 브라우저 저장소를 지우면 함께 사라집니다). 그 외 고객/상품 정보는 저장되지 않고 새로고침하면 사라집니다.

## 파일 구성

- `index.html` — 앱 화면
- `app.js` — 계산 로직 및 결과 요약 생성
- `style.css` — 모바일 우선 스타일(인쇄용 스타일 포함)
- `build.sh` — 위 파일들을 하나의 독립 실행 HTML(`dist/중도해지_패널티_시뮬레이션.html`)로 합쳐주는 스크립트
