# DC·IRP 만기예정 안내 문자 도우미

DC/IRP 고객 중 이번 달(또는 지정한 달) 만기예정자를 엑셀에서 자동으로 뽑아, 고객별 안내 문구를 만들고 휴대폰 기본 문자 앱으로 바로 발송할 수 있게 도와주는 도구입니다.

## 특징

- **개인정보가 기기 밖으로 나가지 않습니다.** 엑셀 업로드부터 문구 생성까지 전부 브라우저(휴대폰/PC) 안에서만 처리되고, 서버로 전송되거나 저장되지 않습니다.
- **별도 비용/API 계약이 없습니다.** 실제 발송은 휴대폰의 기본 문자 앱을 통해 이뤄지므로 기존 통신사 문자 요금제를 그대로 사용합니다.
- 업로드했던 원본 데이터는 새로고침하면 사라집니다. 다만 연락처는 "연락처 DB 저장" 기능으로 이 기기의 브라우저 저장소에 남겨둘 수 있어, 다음부터는 만기상품 파일만 올리면 됩니다(자세한 내용은 아래 사용 방법 참고).

## 사용 방법

가장 간편한 방법: `./build.sh`를 실행하면 `dist/DC_IRP_만기안내문자.html` 파일 하나가 만들어집니다. 이 파일 하나만 휴대폰에 저장해서 열면 인터넷 연결이나 별도 설정 없이 바로 사용할 수 있습니다(코드를 수정했을 때 다시 실행해서 최신 버전을 만드세요).

또는 `index.html`을 휴대폰 또는 PC 브라우저로 직접 열어도 됩니다. (파일을 그대로 열거나, GitHub Pages 등 정적 호스팅에 올려서 URL로 접속해도 됩니다.)

1. 매달 뽑는 **만기상품 엑셀**을 업로드합니다. 연락처가 이 파일에 없고 단체(거래처)별 별도 파일로 관리된다면, 관련된 **연락처 엑셀**들을 한 번에 여러 개 선택해서 함께 업로드합니다(모두 같은 양식이라고 가정하고 병합합니다). 파일에 암호가 걸려있으면 업로드 버튼 아래 비밀번호 입력칸에 입력해주세요(먼저 파일만 선택해도 되고, 나중에 비밀번호를 입력하면 자동으로 다시 시도합니다). 연락처 파일들이 서로 다른 암호를 쓴다면 같은 암호끼리 나눠서 업로드하면 됩니다(연락처 DB는 새로 올릴 때마다 기존 내용과 합쳐집니다).
2. 엑셀의 각 컬럼(고객명/상품유형/상품명/만기일, 그리고 연락처 파일이 있다면 그쪽의 고객명/휴대폰번호)이 무엇에 해당하는지 선택합니다. 두 파일에 동명이인이 있을 수 있으면 "매칭 보조 키"(예: 생년월일)도 양쪽에서 같은 컬럼으로 지정하세요. 다음에도 같은 양식의 엑셀을 쓰면 자동으로 기억해둔 매핑을 불러옵니다.
3. 매핑을 마치면 안내 문자를 보낼 대상 월이 자동으로 채워집니다(업로드한 엑셀의 만기일 컬럼에서 가장 많이 나오는 연-월을 기본값으로 사용 — 예: 이번 달 말에 다음 달 만기예정자 파일을 올리면 자동으로 다음 달이 선택됩니다). 필요하면 직접 다른 월로 바꿀 수 있습니다. "필터링"을 누르면 해당 월 만기예정 고객 목록이 나옵니다. 연락처를 찾지 못한 고객은 목록에서 빠지지 않고 "연락처 없음"으로 표시됩니다. 한 고객에게 같은 달 만기 상품이 여러 개면 한 사람으로 합쳐집니다.
4. 문자 문구를 확인/수정합니다. `{이름}`, `{단체명}`, `{만기내역}`(상품이 1개면 "만기예정일 ~일 / 적립금 계 ~원", 2개 이상이면 건별로 나열 후 적립금 합계까지 자동 계산), `{상품목록}`(상품유형+상품명만 목록으로 나열), `{상품유형}`/`{상품명}`/`{만기일}`/`{적립금}`(그중 첫 번째 상품 기준)이 고객별로 자동 치환됩니다. `{해당월}`은 3번에서 고른 월이고, `{해당월이율}`/`{디폴트옵션이율}`은 고객별 데이터가 아니라 이 화면의 입력칸에 매달 직접 입력하는 값입니다(다음에도 마지막 입력값이 남아있습니다).
5. 고객 목록에서 "문자 보내기"를 누르면 휴대폰 기본 문자 앱이 해당 고객 번호와 문구를 채운 채로 열립니다. "카톡으로 보내기"를 누르면 그 고객 이름이 클립보드에 자동 복사되면서 공유하기 화면이 열리고, 그 안에서 카카오톡을 고른 뒤 검색창에 붙여넣기 하면 대화 상대를 더 빠르게 찾아 선택해서 보낼 수 있습니다(카카오톡 읽음 확인 기능은 개인 계정으로는 지원되지 않아, 어느 고객에게 카톡이 가능한지는 RM님이 직접 판단해서 버튼을 고르시면 됩니다). **어느 쪽이든 그 화면에서 실제로 "보내기"를 직접 눌러야 발송됩니다 — 휴대폰 문자 앱과 카카오톡이 웹페이지에서 전송 버튼까지 자동으로 누르는 것을 허용하지 않기 때문에, 이 마지막 확인 한 번은 어떤 방법으로도 생략할 수 없습니다.** 목록 상단의 이름 검색/발송상태/단체명/상품유형 필터로 대상자가 많을 때도 원하는 사람만 좁혀볼 수 있고, 발송할 때마다 이 기기에 이력(문자/카카오톡 구분 포함)이 남아 화면 아래 "발송 이력"에서 월/이름으로 찾아볼 수 있습니다.

### 한 명씩 순서대로 보내기 (더 편하게 발송하기)

고객이 많으면 목록을 스크롤하며 다음 대상을 찾는 것도 일이라, 5번 화면 상단의 **"한 명씩 순서대로 보내기"** 버튼을 누르면 미발송 고객 한 명만 화면에 크게 표시됩니다. "문자 보내기"나 "카톡으로 보내기"로 발송을 마치면(문자 앱/카카오톡에서 실제 보내기까지 누른 뒤) 화면은 그대로 있고 같은 자리에 다음 미발송 고객이 자동으로 나타나서, 스크롤이나 찾기 없이 같은 동작만 반복하면 됩니다. 모두 처리되면 완료 메시지가 뜨고, 언제든 "목록으로 보기"를 눌러 원래 목록으로 돌아갈 수 있습니다. (이 기능은 발송 자체를 자동화하는 게 아니라, 다음 대상을 찾는 수고만 없애주는 것입니다 — 문자/카카오톡 앱에서 실제 보내기는 여전히 직접 눌러야 합니다.)

### 안내 이미지 첨부 (선택)

4번 문자 문구 화면 아래에 "이미지 선택"으로 안내 이미지(예: 절차 안내문, 상품 안내장 캡처 등)를 하나 등록해두면, 이후 "카톡으로 보내기"를 누를 때 문구와 함께 그 이미지도 같이 공유됩니다(기기/카카오톡 버전이 파일 공유를 지원하는 경우에 한함 — 지원하지 않으면 자동으로 문구만 공유됩니다). **문자(SMS)는 이미지 첨부 자체가 안 되는 방식이라, "문자 보내기"는 항상 텍스트만 발송됩니다.** 등록한 이미지는 이 기기에 저장되어 다음에 접속해도 남아있고, "이미지 삭제"로 언제든 지울 수 있습니다(최대 3MB).

### 연락처 DB (다음 달부터 연락처 재업로드 생략하기)

연락처 엑셀을 올려서 매핑을 마치면, "이름(+보조 키) → 연락처" 형태로 정리된 조회표가 이 기기의 브라우저에 자동 저장됩니다. 다음에 접속하면 업로드 화면 상단에 저장된 연락처 수와 저장 일자가 표시되고, **"이 DB 사용"**을 누르면 연락처 파일을 다시 올리지 않고 만기상품 엑셀만으로 진행할 수 있습니다. 연락처가 바뀌었으면 연락처 엑셀을 새로 올려서 다시 매핑하면 DB가 갱신되고, **"DB 삭제"**로 언제든 지울 수 있습니다.

번호가 바뀐 고객 한두 명만 고칠 때는 전체를 다시 올릴 필요 없이 **"DB 보기/수정"**을 눌러 이름으로 검색한 뒤 연락처를 바로 수정하거나 항목을 삭제할 수 있습니다. 어떤 단체 파일에도 없는 고객은 이름/연락처를 직접 입력해 추가할 수도 있습니다.

**기기 간(폰↔컴퓨터) DB 맞추기**: 이 저장은 브라우저별로 따로 남기 때문에, 폰에서 만든 DB가 컴퓨터에는 자동으로 안 보입니다. **"DB 내보내기"**로 파일을 받아 카카오톡(나에게 보내기)/이메일 등으로 다른 기기에 옮긴 뒤 **"DB 가져오기"**로 불러오면, 그 기기의 기존 DB와 합쳐집니다. 서버를 거치지 않으므로 개인정보가 외부로 나가지 않습니다.

## 참고 (개인정보 처리)

- 엑셀 파일은 브라우저 메모리에서만 파싱되며 어떤 서버로도 업로드되지 않습니다.
- 기본적으로 저장되는 것은 "문자 문구 템플릿"과 "컬럼 매핑(엑셀 헤더명)"뿐이며, 둘 다 개인정보가 아닙니다.
- **연락처 DB 기능을 사용하면 예외적으로 "이름(+보조 키) → 휴대폰번호" 조회표가 이 기기의 브라우저 저장소에 남습니다.** 서버로 전송되지는 않지만, 이 기기/브라우저 안에 평문으로 저장되므로 기기 잠금 등 기본적인 보안은 유지해주세요. 필요 없어지면 "DB 삭제" 버튼으로 즉시 지울 수 있습니다.
- **발송 이력도 마찬가지로 이 기기에만 남습니다** (발송 시각/이름/연락처/상품 요약/문자 내용). "발송 이력" 화면의 "이력 전체 삭제"로 지울 수 있습니다.
- **등록한 안내 이미지도 이 기기의 브라우저 저장소에만 남습니다.** 서버로 전송되지 않으며, "이미지 삭제" 버튼으로 즉시 지울 수 있습니다.
- 엑셀 원본 파일이나 내보낸 결과물을 이 저장소에 커밋하지 마세요(`.gitignore`에서 기본적으로 제외하도록 설정되어 있습니다).

## 파일 구성

- `index.html` — 앱 화면
- `app.js` — 엑셀 파싱, 필터링, 문구 생성, 문자 발송 링크 생성 로직
- `style.css` — 모바일 우선 스타일
- `vendor/xlsx.full.min.js` — 엑셀 파싱 라이브러리(SheetJS, 오프라인 사용을 위해 로컬 포함)
- `vendor/officecrypto.min.js` — 비밀번호로 보호된 엑셀 복호화 라이브러리(officecrypto-tool을 브라우저용으로 번들링)
- `build.sh` — 위 파일들을 하나의 독립 실행 HTML(`dist/DC_IRP_만기안내문자.html`)로 합쳐주는 스크립트
